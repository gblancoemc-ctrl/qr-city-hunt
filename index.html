    Before you start

    Stay on the pavement. Do not block doorways, and do not scan anything that is not this hunt's code.

    Buy something if you use a venue's toilet or table. The venues are not paying for this and they are not obliged to host you.

    No climbing, no touching, no trespassing. Every code is at eye level and reachable from the street side.

    If a code is missing or damaged, message the organiser and you get the clue directly.

    Self-guided. No host on site. Evidence pack, not a compliance claim.
